⭐ 오산고 교직원 포털을 즐겨찾기에 추가

사용하시는 기기·브라우저에 맞는 방법을 참고하세요.

  1. 단축키로 즐겨찾기 창을 엽니다: Ctrl+D (Mac은 ⌘+D).
  2. 이름을 「오산고 교직원 포털」로 두고 저장 위치를 「즐겨찾기 바」로 선택하면 브라우저 상단에 상시 표시됩니다.
  3. 주소창 오른쪽의 별표(☆) 아이콘을 눌러도 같은 결과입니다.
  1. Chrome 주소창 오른쪽 ⋮ 메뉴를 누른 뒤, 상단의 별표(☆) 아이콘을 탭합니다.
  2. 같은 메뉴의 「홈 화면에 추가」를 누르면 앱처럼 아이콘이 생깁니다.
  3. 이후 주소창에 「오산고」만 입력해도 자동 완성으로 빠르게 이동할 수 있습니다.
  1. Safari 하단(또는 상단)의 공유 버튼(⬆)을 누릅니다.
  2. 「홈 화면에 추가」 또는 「즐겨찾기에 추가」를 선택하고 저장합니다.
  3. 홈 화면 아이콘이나 즐겨찾기(책 모양 아이콘)에서 언제든 열 수 있습니다.

🏠 브라우저 시작페이지로 설정

브라우저 보안 정책 때문에 웹 페이지가 시작페이지를 직접 바꿀 수는 없습니다. 아래 링크를 복사한 뒤, 사용하시는 브라우저에 맞는 방법으로 설정해 주세요.

① 포털 링크 복사
② 브라우저에서 설정
  1. 오른쪽 위 ⋮ 메뉴 → 설정을 엽니다.
  2. 왼쪽에서 「시작 그룹」을 누릅니다.
  3. 「특정 페이지 또는 페이지 모음 열기」를 선택하고 「새 페이지 추가」를 누릅니다.
  4. 복사한 링크를 붙여넣고 「추가」를 누르면 끝입니다.
  1. 오른쪽 위 ⋯ 메뉴 → 설정을 엽니다.
  2. 왼쪽에서 「시작, 홈 및 새 탭」을 누릅니다.
  3. 「Edge가 시작되는 경우」에서 「다음 페이지 열기」를 선택하고 「새 페이지 추가」를 누릅니다.
  4. 복사한 링크를 붙여넣고 「추가」를 누르면 끝입니다.
  1. 오른쪽 위 ⋯ 메뉴 → 설정을 엽니다.
  2. 「시작 그룹」 항목을 찾습니다. (설정 화면 위쪽 검색창에 「시작」을 입력하면 빠릅니다.)
  3. 「특정 페이지 또는 페이지 모음 열기」를 선택하고 「새 페이지 추가」를 누릅니다.
  4. 복사한 링크를 붙여넣고 「추가」를 누르면 끝입니다.
홈(🏠) 버튼을 눌렀을 때도 포털이 열리게 하려면, 같은 설정 화면의 「홈 버튼 표시」에 링크를 넣어 주세요. 휴대폰에서는 즐겨찾기 추가 안내의 「홈 화면에 추가」를 이용하시면 됩니다.
